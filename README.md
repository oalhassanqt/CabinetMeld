# CabinetMeld

CabinetMeld enables real-time data integration and auto-scaling across distributed systems via a configurable, high-performance data processing gateway.

With CabinetMeld, you get a lightweight tool that stays out of your way.

**What you get**

- CabinetMeld enables real-time data integration
- and auto-scaling across distributed systems
- via a configurable, high-performance data

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/CabinetMeld.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure CabinetMeld, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
